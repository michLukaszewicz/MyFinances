# MyFinances

## Overview
MyFinances is a personal finance management application designed to help users organize and control their finances. The app connects to bank accounts to download transaction histories and also allows manual transaction entries for flexibility.

## Features
- **Bank Integration**: Automatically sync transaction history from your bank accounts.
- **Manual Transaction Entries**: Add transactions manually for complete control over your finances.
- **Filters and Diagrams**: Visualize and manage finances with interactive filters and diagrams. To let you menage the finaces better.

## Purpose
This project is a work in progress and serves as a practice ground to enhance and apply my knowledge of modern technologies.

## Technology Stack
- **Frontend**: React 19.1.0 with React Router and Recharts for charts
- **Backend**: ASP.NET API (.NET 8)
- **Database**: SQL Server
- **Other Tools**: Entity Framework, ASP.NET Core Identity
